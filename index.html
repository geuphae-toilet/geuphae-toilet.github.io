위치가 틀리면 파란 점을 끌거나 지도를 눌러 바로잡으세요

    데이터: 서울교통공사 역사공중화장실정보(공공데이터포털, 공공누리 제1유형), © OpenStreetMap 기여자. 스타벅스 매장 위치도 OpenStreetMap 기준입니다. 실제 개방 여부는 현장 상황과 다를 수 있습니다.

    📍

    내 주변 화장실을 찾으려면
    위치 권한이 필요해요

    위치는 가까운 화장실을 찾는 데에만 쓰고, 어디에도 저장하거나 보내지 않아요.

    아래 버튼을 누른 뒤 나오는 창에서 허용을 눌러 주세요.

    🔒

    위치 권한이 꺼져 있어요

    브라우저에서 이 사이트의 위치 사용이 막혀 있어요. 아래 방법으로 켠 뒤 다시 시도를 눌러 주세요.

    카카오톡·인스타그램 같은 앱 안에서 열면 위치가 막히는 경우가 많아요. 오른쪽 위 메뉴(⋮ 또는 ···)에서 다른 브라우저로 열기를 눌러 Safari나 Chrome으로 열어 주세요.

    1. 주소창 왼쪽의 가가(또는 aA) 버튼 → 웹 사이트 설정 → 위치 → 허용
    2. 그래도 안 되면: 아이폰 설정 → 개인정보 보호 및 보안 → 위치 서비스 켜기 → Safari 웹 사이트 → 앱을 사용하는 동안
    1. 주소창 왼쪽의 설정 아이콘(자물쇠 모양) → 권한 → 위치 → 허용
    2. 그래도 안 되면: 휴대폰 설정 → 위치 켜기 → 앱 위치 권한 → Chrome(또는 쓰는 브라우저) → 앱 사용 중에만 허용
    1. 주소창 왼쪽의 자물쇠(또는 설정) 아이콘 → 위치 → 허용
    2. 컴퓨터의 위치 서비스가 꺼져 있다면 켜 주세요.
